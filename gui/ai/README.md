# ИИ-ассистент «Квант»

Встроенный в десктопный тестер чат-агент: пишет стратегии под контракт этого
фреймворка, читает метрики тестов, борется с переобучением и объясняет
устройство пакета `backtester`. Работает **только внутри каталога проекта** —
файловый доступ агента жёстко ограничен корнем `main_python_algo`.

Зависимостей помимо уже используемых в проекте (`PySide6`) **не требуется** —
HTTP к LLM идёт через стандартную библиотеку.

## Как открыть

В окне тестера (`python desktop_app.py`) нажмите **«🤖 ИИ-ассистент «Квант»»**
вверху панели настроек. Откроется отдельное окно чата.

## Подключение модели (⚙ Настройки)

Поддерживается любой OpenAI-совместимый эндпоинт `/chat/completions`.

### Вариант 1. OpenRouter (облако)
1. Получите ключ на <https://openrouter.ai/keys>.
2. В «⚙ Настройки» выберите провайдера **«OpenRouter (облако)»**, вставьте ключ
   и модель (напр. `anthropic/claude-sonnet-4.5` — поддерживает текст и
   изображения).
3. Кнопка **«Проверить подключение»** делает пробный запрос.

Ключ можно не вводить в окно, а задать переменной окружения
`OPENROUTER_API_KEY` (или `OPENAI_API_KEY` / `LLM_API_KEY`).

### Вариант 2. Локальная LLM (без ключа)
- **Ollama**: `ollama serve`, затем `ollama pull qwen2.5-coder:14b`. В настройках
  выберите пресет «Локальная — Ollama» (`http://localhost:11434/v1`).
- **LM Studio**: включите локальный сервер, пресет «Локальная — LM Studio»
  (`http://localhost:1234/v1`).
- Любой другой OpenAI-совместимый сервер — пресет «Другой» + свой Base URL.

> Для работы с изображениями нужна vision-модель. Локальные модели без vision
> примут только текст и текстовые вложения.

### Вариант 3. LLM в Google Colab через туннель
Colab не имеет публичного адреса, поэтому сервер модели нужно «пробросить»
наружу туннелем. Запустите в ноутбуке OpenAI-совместимый сервер (Ollama, vLLM
или llama.cpp server) и поднимите туннель — **ngrok** или **Cloudflare**. В
настройках выберите соответствующий пресет и вставьте выданный `https`-адрес,
дописав `/v1`. Ключ не нужен.

```python
# Пример (Ollama + Cloudflare Tunnel, без токена):
!curl -fsSL https://ollama.com/install.sh | sh
import subprocess, time
subprocess.Popen(["ollama", "serve"]); time.sleep(5)
!ollama pull qwen2.5-coder:7b
!wget -q https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 -O cloudflared
!chmod +x cloudflared
# выведет https://xxxx.trycloudflare.com — в настройках укажите .../v1
!./cloudflared tunnel --url http://localhost:11434
```

```python
# Пример (ngrok):
!pip -q install pyngrok
from pyngrok import ngrok
ngrok.set_auth_token("ВАШ_NGROK_ТОКЕН")
print(ngrok.connect(11434).public_url)   # https://xxxx.ngrok-free.app  -> .../v1
```

Для ngrok ассистент сам шлёт заголовок `ngrok-skip-browser-warning`, чтобы
вместо JSON не пришла HTML-страница предупреждения. Адрес туннеля меняется при
каждом перезапуске Colab — обновляйте Base URL в настройках.

Настройки сохраняются в `.ai_assistant.json` в корне проекта (файл в
`.gitignore` — ключ в репозиторий не попадает).

## Возможности

- **Чат с потоковым ответом**, Markdown-разметка, подсветка кода.
- **Вложения**: текстовые файлы (код, CSV, отчёты) и изображения (графики
  эквити, скриншоты) — кнопки «📎 Файл» и «🖼 Картинка».
- **Контекст приложения**: агенту автоматически передаётся снимок текущего
  состояния тестера — данные, выбранная стратегия, параметры и **последние
  результаты** бэктеста, оптимизации, WFA, матричного WFO и Монте-Карло.
- **Инструменты агента** (исполняются строго внутри проекта):

  | Инструмент | Назначение |
  |---|---|
  | `list_directory` | заглянуть в структуру каталога |
  | `read_file` | прочитать реальный код/конфиг/отчёт перед рассуждением |
  | `write_file` | создать/переписать файл стратегии — **с подтверждением пользователя** |
  | `validate_strategy` | прогнать стратегию в подпроцессе: бэктест + анти-lookahead |

  Запись файлов всегда требует ручного подтверждения в диалоге.

## Системный промпт

Агент сконфигурирован как senior quant-исследователь с «доктриной борьбы с
переобучением» (OOS > IS, WFE, поиск плато вместо пика, Deflated Sharpe,
Монте-Карло, размер выборки, множественное тестирование, реализм издержек).
При включённой опции в системный промпт вшивается контракт стратегий
[AI_STRATEGY_RULES.md](../../AI_STRATEGY_RULES.md), поэтому сгенерированные
стратегии подключаются к проекту без правок.

См. текст промпта в [system_prompt.py](system_prompt.py).

## Архитектура

```
gui/ai/
├── config.py           — настройки подключения (провайдер, ключ, модель)
├── llm_client.py       — стриминговый OpenAI-совместимый клиент (urllib, SSE)
├── project_context.py  — песочница файлов проекта + снимок состояния GUI
├── tools.py            — схемы инструментов + их исполнение
├── _validate.py        — изолированная проверка стратегии (подпроцесс)
├── system_prompt.py    — личность «Квант» + доктрина + карта проекта
├── worker.py           — агентный цикл в QThread (стриминг + tool-calling)
├── settings_dialog.py  — диалог настроек подключения
└── chat_window.py      — окно чата (AssistantWindow)
```
